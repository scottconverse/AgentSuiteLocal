# AgentSuiteLocal v1.0 Milestone Plan

**Status:** Active. Replaces the prior 10-sprint v0.9→v1.0 plan in
`handoff_2026-05-06-agentsuitelocal-v090-sprint1-day2.md`.

**Spine:** `/ship` skill (autonomous executor) per sprint.
**Discipline:** layered audit pattern (per-commit careful-coding,
per-checkpoint sanity, per-sprint audit-lite, per-release audit-team).
**Calibration gates:** hard stops between sprints. Three Scott
approvals across the entire 1.0 push.

---

## What changed from the 10-sprint plan

The prior plan committed sprints 1–10 to v1.0. After triage on
2026-05-07, sprints 3, 4, 6, 7, 8 (most of), and 9 were classified
as "robustness / polish / forward-looking" rather than 1.0-blocking.
They slip to 1.1.

**1.0 must include:**
- Test honesty (no lying mocks; MOCKING_AUDIT.md sweep)
- V1/V2 production bug fix (qa_score reliability)
- Bundle integrity smoke (post-PyInstaller first-launch verification)
- Supply-chain hygiene (agentsuite pinned to commit SHA)
- Honest schema (decide `RunRequest.constraints` — wire or remove)
- Bare-min a11y (Tab nav, focus rings, no keyboard traps)
- Final audit-team gate and CHANGELOG/doc-currency sweep

**1.0 explicitly does NOT include** (slip to 1.1):
- Recovery sweeps for Ollama crash / model corruption / disk full /
  key revoke / concurrent runs
- Performance baseline + benchmarks/ harness
- Frozen API surface + schema-change CI
- Full WCAG AA / screen-reader audit / localization
- Landing page polish, code signing, multi-instance, plugin system,
  auto-update, Linux installer, Windows arm64

## Sprint A — Test honesty + bundle integrity + a11y bar

**Goal:** Convert the test suite from mock-heavy to behavior-truthful;
verify the bundled installer actually runs on first launch; meet the
bare-minimum a11y bar.

**Driven by:** `/ship` (autonomous within sprint).

**Checklist (in order):**

1. Trigger `real-e2e.yml` on `release/v0.9.0` HEAD; verify 5
   consecutive green runs. Remove the `@pytest.mark.xfail` from
   `tests/test_real_founder_run.py` once green.
2. MOCKING_AUDIT.md sweep — read every `patch(...)` in `tests/`,
   classify boundary-mock-OK vs internal-mock-suspect. Refactor any
   internal-mock-suspect tests in `test_execution_state_machine.py`
   to use `AGENTSUITE_LLM_PROVIDER_FACTORY` (real-resolver path) or
   delete as redundant with `test_real_founder_run.py`.
3. Restore the `assert not "Run failed" within 3s` check in
   `tests/e2e/test_new_run.py` (was removed in v0.8.9 because mocks
   couldn't satisfy the agent contract).
4. Decide and act on `RunRequest.constraints` — wire or remove (see
   "Decisions to lock" below).
5. Post-PyInstaller smoke: cleanroom Docker build + cleanroom .exe
   + cleanroom .dmg + first-launch end-to-end (installer walk →
   start a run → reach approval gate). Add this as a CI step on
   `release/v0.9.0`.
6. Bare-min a11y:
   - Tab order through every primary view.
   - Visible focus rings on every interactive element.
   - No keyboard traps in modals (Esc closes, focus returns).
   - `aria-current="page"` on the active sidebar nav item (UX-008).
7. CHANGELOG `[Unreleased]` complete; README "Recent releases"
   section accurate up to current state.
8. **Sprint-end audit-lite** (4-lens, scoped to the sprint diff).
9. **Sprint A ship gate (Scott approval).**

**Definition of done:**
- 5 consecutive green real-e2e CI runs
- MOCKING_AUDIT.md exists with every patch classified
- Cleanroom .exe + .dmg + Linux build run installer + start run
  successfully
- a11y manual check passes (Tab nav, focus rings, aria-current)
- Audit-lite returns 0 Criticals, ≤2 Majors

**Hard stop:** Scott reviews VERIFICATION_LOG.md and audit-lite
output before Sprint B starts.

every Critical that fits; queue the rest for 1.1.

**Driven by:** `/ship` with audit-team as the centerpiece.

**Checklist:**

2. Read `00-executive-audit.md` + `sprint-punchlist.md`.
3. Fix every **Blocker** finding (no exceptions).
4. Fix every **Critical** finding that fits Sprint B's time-box.
5. Major → queue in `docs/next-cleanup.md` for 1.1.
6. Minor / Nit → queue or fix inline if trivial.

- 0 Blockers, 0 Criticals open
- All audit-team doc-rewrites either merged or rejected with reason

queue before Sprint C starts.

## Decisions locked (2026-05-07)

### D1 — `RunRequest.constraints`: **REMOVE** ✅

Drop the field from `RunRequest`. Update API contract doc to reflect.
The field was accepted by the API but stored in no run record and
never passed to `_AgentRequest` — dead schema that eroded API trust.

### D2 — A11y bar: **Bar 1** ✅

For v1.0:
- Tab nav works through every primary view
- Visible focus rings on every interactive element
- No keyboard traps in modals (Esc closes, focus returns)
- `aria-current="page"` on active sidebar nav item

Bar 2 (skip-to-content + ARIA labels + alt text) and Bar 3 (full
WCAG AA + screen-reader audit) slip to v1.1.

### D3 — Concurrent runs: **DOCUMENTED LIMITATION** ✅

v1.0 supports one run at a time per session. Add to README +
user-manual + FAQ: "v1.0 supports one run at a time per session.
Concurrent runs land in v1.1." Recovery-sweep work that covered
robust concurrent runs (W-15) slips to v1.1.

### D4 — Real-e2e branch trigger removal: **SPRINT B** ✅

`real-e2e.yml` has a push trigger on `release/v0.9.0` that was
added for sprint-time CI convenience. Remove in Sprint B after
V1/V2 is confirmed closed by ≥3 consecutive green runs (already
have 1 green from `d707fac`; need 2 more from subsequent pushes).
Tracked as ENG-0907-008.

## Calibration triggers (auto-replan if hit)

- **Sprint A runs >30% over budget:** stop. Re-scope. Maybe ship
  v0.9.0 from current state and defer 1.0 to a separate milestone.
- **audit-team in Sprint B surfaces a Critical the sprint-A
  audit-lite missed:** stop. Re-plan B with the new finding;
  audit-lite scope was too narrow.
- **Real-e2e fails 3 consecutive runs after V1/V2 fix:** stop.
  V1/V2 fix is incomplete. Diagnose before continuing.

---

## What's NOT in this plan

Per the layered-audit overflow rule, finds at lower altitudes
(per-commit careful-coding) get triaged by severity, not folded in:
- **Blocker** stops the sprint.
- **Critical** only if it fits remaining time.
- **Major** queues to next sprint or 1.1.
- **Minor / Nit** collects in `docs/next-cleanup.md`.

The plan WILL NOT silently expand. If new scope is needed, the
calibration trigger fires and Scott decides.
