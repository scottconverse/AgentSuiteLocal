How it works

Three steps from intent to artifact

No configuration files. No cloud accounts. No subscriptions. Just install, type a goal, and approve the output.

1

Install

Run the installer. It detects Ollama, downloads the model you choose, and verifies everything is working with a smoke test before you ever touch the main app.

2

Run an agent

Choose an agent, type one sentence describing your goal, optionally point it at a folder of notes. The five-stage pipeline runs in 9–16 minutes and writes structured markdown artifacts to your disk.

3

Review and approve

The Approval Gate shows every artifact with rendered markdown, a QA score across nine dimensions, and a diff against prior versions. Approve what's good — it feeds every future run on that project.

The agents

Seven specialists, one goal field

Each agent is pre-configured with a domain-specific pipeline and QA rubric. You write the goal; the agent handles the structure.
