Five stages. Every run.

Every agent walks the same pipeline. Input your goal once — the pipeline handles the rest.

01
Intake
Validates the request and manifests any input files you provide.
02
Extract
Pulls structured context from your inputs — notes, documents, research.
03
Spec
Generates the core artifact library — typically 10 markdown files.
04
Execute
Builds brief templates and an export manifest from the spec output.
05
QA
Scores output across 9 dimensions. Gate: approve if composite ≥ 7.0.

Why run it locally

The whole point is that your business context never leaves your machine.

🔒

Your data stays on your disk

No cloud, no API key, no telemetry. The model runs in Ollama. Your artifacts are files. Nothing leaves your machine unless you send it.

💰

No per-run cost

Run every agent on every project as many times as you want. The only cost is electricity. An API-backed equivalent would cost $3–8 per run.

📁

Artifacts are plain markdown

Every artifact is a markdown file on your disk. Version-control them, edit them, commit them. No proprietary format, no lock-in.

🧠

The kernel compounds

Approved artifacts become canonical context for every future run. Each run builds on what you've approved before. The system gets more useful the more you use it.

🛠️

Hackable

FastAPI backend, React frontend, standard Python packaging. Fork it, extend it, wire it to your own tools. MIT license.

🖥️

Works offline

Once the model is pulled, everything runs without internet. Take it on a plane. Use it in a SCIF. Works wherever your laptop does.

The installer handles everything

Open the app once and a guided installer walks you through Ollama setup, model download, Python runtime, agent selection, and a smoke test — no terminal required.

🔍

Hardware check

Reads your CPU, RAM, and disk. Recommends the right model tier automatically.

⚙️

Ollama setup

Detects if Ollama is installed. If not, installs the bundled copy — one click, no admin password.

⬇️

Model download

Pulls the model with a live progress bar. One-time download, then fully offline.

🐍

Runtime setup

Unpacks and verifies the bundled Python environment. Nothing to install manually.

✅

Smoke test

Runs a quick end-to-end check before handing you over to the main app.
